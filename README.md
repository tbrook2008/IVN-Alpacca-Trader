# IVN Alpaca Trader

IVN Systems' official autonomous trading agent for the Alpaca AI Trading Agents Hackathon. 

## Overview
This repository contains an AI-driven algorithmic trading bot designed to execute strategies across both Index and Options markets using the Alpaca Trading API. The system is built with robust risk management and leverages Alpaca's Model Context Protocol (MCP) server for intelligent trade execution.

## Features
- **Multi-Asset Strategies**: Concurrent trading capabilities across Index assets and Options.
- **AI-Driven Logic**: Intelligent market analysis and dynamic position sizing.
- **Strict Risk Controls**: Hardcoded limits to protect capital and manage drawdowns.
- **Paper Trading Environment**: Fully integrated with Alpaca's paper trading ecosystem for safe testing.
